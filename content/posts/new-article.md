## 图片展示示例

### 方法一：普通 Markdown 语法
```markdown
![图片描述](/images/example.jpg)
```

### 方法二：HTML 标签（更多控制）
```html
<img src="/images/example.jpg" alt="图片描述" width="500">
```

### 方法三：Hugo 主题的 image shortcode
```markdown
{{< image src="/images/example.jpg" alt="图片描述" position="center" style="border-radius: 8px;" >}}
```
