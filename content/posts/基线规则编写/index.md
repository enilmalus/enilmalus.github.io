基线规则是依据预先制定的安全配置标准，对主机、操作系统、数据库、中间件等系统组件的试剂配制进行检查和比对，以发现弱口令、权限过大、危险服务未关闭、日志未开启等安全隐患。

原理为通过规则化方式采集系统配置并与基线要求逐项比对，判断是否符合安全标准。

## CIS 基线

1. 账号安全

检查诸如 密码复杂度、密码长度、密码过期时间、禁用默认账号。

例如：

```bash
密码长度 > 14
开启密码复杂度
连续登录失败锁定账号
```

2. 权限控制
3. 关闭不必要服务
4. 网络安全配置
5. 日志审计
6. 系统更新

### Nessus 基线规则

Nessus 基线规则指在 Nessus 漏洞扫描器中，用于检查目标系统是否符合某套安全配置规则标准的规则合集。

例如 Nessus 基线扫描发现的是：

```bash
SSH PermitRootLogin 设置为 yes
风险：
	允许 root 远程登陆
建议：
	修改为 no
```

Nessus 基线包含：

1. 密码策略规则
2. 用户账号规则
3. 服务配置规则
4. 网络配置规则
5. 日志审计规则 
6. 文件权限规则
