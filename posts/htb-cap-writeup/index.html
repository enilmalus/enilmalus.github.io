Web 渗透

80 端口是一个 wordpress 的 Dashboard 界面，使用的主题是 Colorlib。

进入 Security Snapshot 界面发现可以下载 cap流量包，且地址处的 data 后数字每次访问都会改变。

猜测 data/0 会有有价值的数据，下载到 kali 中进行分析。
