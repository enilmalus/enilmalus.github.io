Mount

检查共享目录

showmount -e 10.10.10.13

连接共享目录

sudo mount -t nfs 10.10.10.13:/home/karl attact

Smbclient

列出 SMB 共享

sudo smbclient -N -L \\\\10.10.10.10

连接到 SMB 共享

sudo smbclient \\\\10.10.10.10\\enil
