  • -c：表示 command，指定执行的系统命令

  • START /B：启动新进程，在 Windows 上后台运行，不打开新窗口。这里是执行一个后台任务

  • -o：指定输出的格式

  • -g：表示使用的 gadget，它们在反序列化过程中可以被利用来执行任意代码。ObjectDataProvider 是此处指定的 gadget 类型，是 WPF 框架中的一个类，常用于执行命令注入。

  • -f：指定序列化框架

  • ViewState 反序列化攻击
