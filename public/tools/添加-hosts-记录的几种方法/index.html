添加 hosts 记录

Bash

sudo bash -c 'echo "10.129.187.74 conversor.htb" >> /etc/hosts'

Sed

┌──(kali㉿kali)-[~/Work/Kali]
└─$ sudo sed -i '1i 10.129.227.191 json.htb' /etc/hosts

Tee

sudo echo "10.129.227.191 json.htb" | tee -a /etc/hosts
